
#  Real-Time Chat Application

A real-time web-based chat application developed using **Java WebSocket**, **JSP**, and **Oracle Database** that enables users to communicate instantly through one-to-one messaging with advanced chat features.

---

##  Features

*  User Login System
*  One-to-One Real-Time Messaging
*  Instant Communication using WebSockets
*  Online/Offline User Status
*  Typing Indicator
*  Seen/Blue Tick Functionality
*  Persistent Chat History
*  Responsive and Interactive User Interface
